# hxwl-05 水族箱水质监测

多鱼缸水质趋势、换水和异常指标提醒

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 初始功能

- 领域指标看板
- 角色和分类筛选
- 专业字段录入区
- 示例记录列表
- 可继续扩展IndexedDB、权限、后端API和复杂图表

## 鱼缸用药与停药期管理

位于水质监测页下方（`src/medication/`），不新增任何依赖，四个模块相互独立：

- `catalog.ts` 资料：鱼缸容量与单升投药上限、药品目录与初始库存
- `dose.ts` 剂量计算（纯函数）：缸体上限、整疗程药量、整批校验、换水顺延天数
- `store.ts` 保存：localStorage 持久化与纯状态迁移（疗程 / 换水事件 / 版本快照原子写入）
- `ui/` 与 `MedicationPage.tsx` 界面：批量登记、疗程列表、换水记录、资料侧栏

规则：

- 登记字段：鱼缸、病症、药名、单次剂量、投药时刻、疗程天数，支持整批多行
- 同缸已有未结疗程、剂量超缸体上限（容量 × 单升上限）、整批药量汇总超库存时，整批拒绝并保留全部输入，受阻行显示鱼缸、药名与库存差额
- 疗程中换水默认暂停；确认后按 `顺延天数 = ⌈换水量% × 剩余疗程天数⌉`（至少 1 天）顺延实际停药日
- 提前撤药必须填写原因，生成新版本快照，历史版本可查；到期未撤药自动追加结案版本
- 重新打开页面后疗程、换水顺延与版本从本机存储恢复，仍一一对应
