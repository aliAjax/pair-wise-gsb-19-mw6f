# hxwl-05 水族箱水质监测

多鱼缸水质趋势、换水和异常指标提醒

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 初始功能

- 领域指标看板
- 角色和分类筛选
- 专业字段录入区
- 示例记录列表
- 可继续扩展IndexedDB、权限、后端API和复杂图表

## 鱼缸用药与停药期管理（src/medication）

在水质监测页新增独立面板，支持批量登记鱼缸、病症、药名、剂量、投药时刻与疗程天数。

- **整批拒绝**：同缸存在未结疗程、单次剂量超过缸体上限、或本批某药合计用量超过库存时，整批不保存并原样保留输入；受阻提示包含鱼缸、药名与库存差额。
- **换水顺延**：疗程中换水先暂停疗程，按「换水量 / 缸体容量 × 剩余疗程天数」（向上取整，至少 1 天）顺延停药日。
- **提前撤药**：必须填写原因，自动新建版本；每次换水也生成版本，旧疗程天数与停药日可逐条回溯。
- **持久化**：数据存于 localStorage（key：`hxwl-05-medication-v1`），重开页面后疗程、换水顺延记录与版本号仍一一对应。

模块相互独立、不增加任何依赖：

| 文件 | 职责 |
| --- | --- |
| `medication/types.ts` + `catalog.ts` | 资料（鱼缸容量/剂量上限、药品库存） |
| `medication/dose.ts` | 纯函数：停药日计算、换水顺延天数、整批校验 |
| `medication/store.ts` | localStorage 保存与疗程/换水/版本状态变更 |
| `medication/MedicationPanel.tsx` | 界面 |
